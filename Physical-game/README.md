# Физикум 2.0 — Интерактивная физическая лаборатория

Интерактивная веб-песочница для моделирования физических экспериментов по трём разделам курса общей физики: **Механика**, **Геометрическая и волновая оптика** и **Электричество (цепи постоянного тока)**.

## Разделы и физические модели

### 1. ⚙️ Механика
- **Движение твёрдых тел в поле тяжести:** упругие шары и бруски с настраиваемой массой $m$, коэффициентом трения скольжения $\mu$ и коэффициентом восстановления (упругости) $e$.
- **Наклонная плоскость и опоры:** произвольный угол наклона $\alpha$, качение шаров и скольжение тел с учётом силы реакции опоры $\vec{N}$ и силы трения Кулона.
- **Пружинный осциллятор (закон Гука):** колебания груза на пружине $m\ddot{x} = -kx - c\dot{x}$, визуализация растяжения/сжатия и расчёт периода $T = 2\pi\sqrt{m/k}$.
- **Математический маятник:** численное интегрирование нелинейного уравнения $\ddot{\theta} = -\frac{g}{L}\sin\theta - \gamma\dot{\theta}$, возможность оттягивать груз мышью и соударение груза маятника с телами.
- **Телеметрия и графики:** построение графиков кинетической ($E_k$), потенциальной ($E_p$) и полной механической энергии в реальном времени.

### 2. 🔦 Оптика
- **Двумерная трассировка лучей (2D Ray-Tracing) в реальном времени.**
- **Источники света:** параллельный пучок, одиночный лазер, расходящийся точечный источник; выбор длины волны (белый свет или монохроматические линии).
- **Тонкие линзы:** собирающие ($+F$) и рассеивающие ($-F$) линзы, отображение главных фокусов $F$ и двойных фокусов $2F$, расчёт оптической силы $D = 1/F$.
- **Зеркала:** плоские, вогнутые и выпуклые сферические зеркала.
- **Стеклянная призма с дисперсией:** преломление по закону Снеллиуса ($n_1\sin\theta_1 = n_2\sin\theta_2$), полное внутреннее отражение при превышении критического угла и разложение белого луча в 7-цветный спектр (опыт Ньютона).

### 3. ⚡ Электричество
- **Интерактивная сборка схем:** протягивание проводов от клеммы к клемме с магнитной привязкой.
- **Матричный расчёт цепей (Modified Nodal Analysis):** точное решение системы уравнений узловых потенциалов $\mathbf{G}\mathbf{V} = \mathbf{I}$ методом Гаусса для последовательных, параллельных и смешанных цепей.
- **Элементы:** источник ЭДС (с внутренним сопротивлением и индикацией короткого замыкания), резистор (с тепловым нагревом), лампа накаливания (свечение пропорционально мощности $P = UI$, перегорание при перегрузке), ключ, амперметр и вольтметр.
- **Визуализация тока:** движение зарядов по проводам со скоростью, пропорциональной силе тока $I$.

## Запуск проекта
Проект не требует установки сборщиков:
1. Откройте файл `Physical game/index.html` в любом современном браузере, **или**
2. Запустите локальный сервер из папки проекта:
   ```bash
   python -m http.server 8080
   ```
   и перейдите по адресу `http://localhost:8080/Physical%20game/`.
